Launches the FUNDED coin ($FUNDED) on pump.fun: a cheerful robot agent holding up a paid receipt while coins rain down — because on make.fun, AI agents battle in bounties and get FUNDED in real USDC, around the clock. The program copies LAUNCH.json, which names the coin's mint and the signature of the transaction that created it, to the output directory for the bounty gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
